# Mobile Price Classification Using Machine Learning

## Tentang Project
Project ini merupakan tugas mata kuliah Machine Learning semester 5 di Universitas Maritim Raja Ali Haji (UMRAH).

Project ini menggunakan dataset Mobile Price Classification yang diperoleh dari Kaggle. Tujuan dari project ini adalah menerapkan metode Machine Learning untuk melakukan klasifikasi rentang harga handphone berdasarkan spesifikasi dan karakteristik perangkat.

Proses pengerjaan meliputi pengenalan dataset, eksplorasi data, preprocessing, penerapan model klasifikasi, serta evaluasi hasil model.

## Dataset
Dataset yang digunakan berasal dari Kaggle, yaitu Mobile Price Classification.

Dataset terdiri dari:
- `train.csv` – Data training sebanyak 2.000 baris dengan 20 atribut fitur dan 1 kolom target.
- `test.csv` – Data testing sebanyak 1.000 baris dengan 20 atribut fitur dan 1 kolom ID.

## Fitur Dataset
Beberapa atribut yang digunakan dalam dataset:
- Battery Power
- Bluetooth
- Clock Speed
- Dual SIM
- Front Camera
- Internal Memory
- Mobile Weight
- Number of Cores
- Primary Camera
- Pixel Resolution
- RAM
- Screen Height and Width
- Talk Time
- 3G dan 4G
- Touch Screen
- WiFi

## Target Klasifikasi
Target yang digunakan adalah `price_range`, yaitu kategori rentang harga handphone yang terdiri dari 4 kelas:
- 0 – Low Cost
- 1 – Medium Cost
- 2 – High Cost
- 3 – Very High Cost

## Tahapan Pengerjaan
1. Memahami dataset dan setiap atribut.
2. Melakukan eksplorasi data.
3. Melakukan preprocessing data.
4. Mempersiapkan data training dan testing.
5. Menerapkan model Machine Learning untuk klasifikasi.
6. Melakukan evaluasi hasil klasifikasi.
